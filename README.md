# 🎬 CinePick - Movie Recommendation System
CinePick, kullanıcıların ilgi alanlarına göre film keşfetmelerini sağlayan, Python Flask tabanlı modern bir web uygulamasıdır. Bu proje, İstanbul Ticaret Üniversitesi Bilgisayar Programcılığı programı kapsamında bir okul projesi olarak geliştirilmiştir.

# 🚀 Öne Çıkan Özellikler
- Gerçek Zamanlı Veri: TMDB API entegrasyonu sayesinde en güncel film bilgilerine erişim.

- Dinamik İçerik: Flask ve Jinja2 kullanılarak oluşturulmuş, kullanıcı etkileşimine göre değişen sayfalar.

- Veri Yönetimi: SQLite kullanılarak oluşturulmuş sağlam bir veritabanı yapısı.

- Modern Arayüz: Kullanıcı dostu ve estetik HTML/CSS tasarımı.

# 🛠️ Teknik Yığın (Tech Stack)
- Backend: Python (Flask)

- Frontend: HTML5, CSS3, JavaScript

- Veritabanı: SQL (SQLite)

- API: The Movie Database (TMDB) API

# 📋 Kurulum ve Çalıştırma
Projeyi kendi yerel ortamınızda çalıştırmak için:

- Depoyu klonlayın: git clone https://github.com/upurart/CinePick.git

- Gerekli kütüphaneleri yükleyin: pip install -r requirements.txt

- .env dosyası oluşturun ve TMDB API anahtarınızı ekleyin.

- Uygulamayı başlatın: python app.py
